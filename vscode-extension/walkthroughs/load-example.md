# Load an example

An example is the shortest documentation there is. Four are built in, each
leaning on a different feature:

- **Halbach** — two magnet rings, each built from one magnet and one circular pattern
- **Solenoid** — a linear pattern of current loops
- **Facing pair** — two magnets built with a mirror
- **Magnet array** — a grid from one linear pattern applied twice

Every one is parametric: change a variable in the Variables view and the
whole arrangement rebuilds.

[Load Example Scene…](command:magpylib-studio.loadExample)
