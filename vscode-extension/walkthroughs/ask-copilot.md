# Edit it from chat

Magpylib Studio registers tools Copilot Chat can call directly on the live
scene: add or remove objects, move and rotate them, change style, arrange a
ring or a grid, and compute the field at a point. Try a prompt like:

> add a green sphere at [0,2,0] #magpyAdd

> make the cube green #magpyEdit

A successful edit refreshes the Studio panel automatically, so you see the
result as it lands.
